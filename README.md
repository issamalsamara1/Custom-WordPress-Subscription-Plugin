# Custom WordPress Subscription Plugin

**A powerful WordPress plugin for managing subscription plans, automatic payments, and subscriber management with Stripe integration.**

## Features

- Create and manage subscription plans
- Automatic monthly payments
- Subscriber management dashboard
- Stripe payment gateway integration
- Reports and analytics for subscriptions
- Easy to install and configure

## Installation

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure your subscription plans in the admin panel

## Technologies Used

- PHP
- WordPress Plugin API
- WordPress Hooks & Filters
- Stripe API
